# Third-party licenses

FlashTalk AAC is MIT-licensed (see `LICENSE`). It bundles two fonts under
their own, different licenses — both are compatible with use in an
MIT-licensed, commercial app; neither requires this project to change its
own licensing.

## OpenDyslexic

- **Used for:** the "Dyslexia-friendly" font option (Settings → Font, and
  onboarding).
- **Files:** `app/src/main/res/font/opendyslexic_regular.otf`,
  `app/src/main/res/font/opendyslexic_bold.otf`
- **License:** SIL Open Font License, Version 1.1. Full text:
  `app/src/main/assets/font_licenses/OPENDYSLEXIC_OFL.txt`
- **Copyright:** (c) 2019-07-29, Abbie Gonzalez (https://abbiecod.es), with
  Reserved Font Name OpenDyslexic. (c) 12/2012-2019.
- **Source:** https://github.com/antijingoist/opendyslexic

## Atkinson Hyperlegible

- **Used for:** the "Easy Read" font option (Settings → Font, and
  onboarding).
- **Files:** `app/src/main/res/font/atkinson_hyperlegible_regular.ttf`,
  `app/src/main/res/font/atkinson_hyperlegible_bold.ttf`
- **License:** SIL Open Font License, Version 1.1. Full text:

- **Copyright:** 2020 Braille Institute of America, Inc.

## What the OFL actually permits

Both fonts may be used, studied, copied, modified, and redistributed
freely, including embedded in a commercial application, exactly as done
here — the one restriction that matters for this project is that the
fonts themselves can't be sold standalone, separately from the software
they're bundled with, which was never the plan. Neither font's Reserved
Font Name ("OpenDyslexic", "Atkinson Hyperlegible") may be used to label a
*modified* version of that font — not a concern here either, since both
are bundled unmodified, exactly as downloaded from their source
repositories above.
